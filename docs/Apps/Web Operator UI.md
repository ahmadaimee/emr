# Web Operator UI

`apps/web` — Next.js 16 App Router. The operator's whole working surface.

Typography is Inter, Instrument Sans, and Geist Mono over Grove design tokens
([[Package - ui]]). Light and dark themes resolve before first paint via a blocking
script in the document head, so there is no flash.

## Route groups

`(auth)` — `/login`, `/mfa` · `(app)` — everything behind a session.

## Sections

| Route | Purpose |
|---|---|
| `/dashboard` | Practice health at a glance |
| `/queues` | The exception queue — see [[Automation and Exceptions]] |
| `/claims`, `/claims/[id]` | Claim workspace: status, timeline, logs hub, notes, filing |
| `/claims/[id]/hcfa` | CMS-1500 form view, rendered by [[Package - forms]] |
| `/patients`, `/patients/[id]` | Demographics, coverage, SOAP notes, documents, merge |
| `/eligibility` | 270/271 checks — [[Eligibility]] |
| `/claim-status` | 276/277 inquiries |
| `/authorizations` | Auth and referral tracking |
| `/batches` | Submission batch management |
| `/payments`, `/remittances` | Posting and ERA review — [[Remittance and Payment Posting]] |
| `/reports` | Governed metrics via [[Package - reporting]] |
| `/settings/*` | Rules, fee schedules, providers, organization, EDI, users, audit, automation |

Remittances sit under Payments in the navigation tree; the command palette follows the
same tree, so keyboard and mouse navigation agree.

## Server actions, not a client API

Mutations are Next.js server actions in each route's `actions.ts`, calling
[[Package - domain]] inside `withTenant`. The browser never holds a database credential
or a tenant id it could tamper with — see [[Multi-Tenancy and RLS]].

## Demo mode

`src/lib/mock-data.ts` backs a synthetic demo mode so the UI renders without a database.
Per [[Non-Negotiable Rules|rule 1]] this data is entirely synthetic, and it must stay
that way — it is the fixture most likely to be casually copied from something real.

## Next.js version caveat

`apps/web/AGENTS.md` is generated by `next dev` and warns that this Next.js version has
breaking changes relative to older knowledge. Check `node_modules/next/dist/docs/`
before relying on remembered App Router behaviour.
